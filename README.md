# neonkill - простая игра на html вдохновленная cs2 и ultrakill
Версия 0.1 - Базовый прототип (Каркас)
Движок и мир: Запуск Three.js, базовая перспектива от первого лица, простая арена с полом и границами-стенами.

Управление: Базовое перемещение на WASD, прыжки и мышь для обзора.

Основа стрельбы: Самый первый базовый арсенал (Керамбит и пистолет USP-С) с простейшей регистрацией попаданий.

Враги: Появление первых стандартных врагов-рашеров, которые просто бегут за игроком.

Версия 0.2 - Динамика и «Ганплей» (The Movement & Gunplay Update)
Продвинутая физика: Добавлены подкаты, рывки (Dash) с кулдауном и авто-бханхоп при удержании пробела.

Расширение арсенала: Появились новые пушки (Glock-18, Desert Eagle, AK-47, M4, AWP, дробовик) со своей отдачей, зумом и перезарядкой.

Звуковой движок: Полностью синтезированные звуки на Web Audio API (выстрелы, шаги, попадания, звуки интерфейса) без внешних аудиофайлов.

Система стиля: Внедрена шкала стилей (как в Ultrakill) с рангами (Brutal, Destructive, Ultrakill!) за красивые убийства в прыжке или без прицела.

Версия 0.3 - Разнообразие мира, ИИ и Экономика
Карты и окружение: Добавлена смена тем оформления карт (Cyber, Neon, Dust, Warehouse и др.) с процедурной генерацией укрытий и коробок.

Новые противники: В игру ворвались Снайперы с лазерными целеуказателями, Бомберы, кидающие гранаты, быстрые Ниндзя и бронированные Джаггернауты.

Магазин и экономика: Полноценная фаза закупки между раундами на клавишу [B], покупка патронов, брони, шлемов и апгрейдов урона.

Интерактив: Возможность подбирать и выкидывать оружие ([V], [E]), бросать гранаты ([G]) и монетки для рикошетов.

Версия 0.4 - Контентный буст и Боссы (Стабильная база)
Мини-игры: Появление разнообразных режимов-микроигр каждые 7 раундов (от Target Range и Bhop Run до Knife Only и дуэлей со снайперами).

Эпический босс: Добавлен финальный босс Overlord (каждые 50 раундов) с тремя фазами боя и уникальными атаками.

Визуальная полировка: Всплывающий урон при попаданиях, динамические трессеры пуль, следы крови, анимации смерти противников и система мульти-киллов (Double Kill, Rampage, Godlike).
